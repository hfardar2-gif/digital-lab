# FARDAR — Industrial Digital Lab

Four-language portfolio and consulting website for Hamidreza Fardar.

## Structure

- `dist/index.html` — semantic page structure
- `dist/assets/styles.css` — visual system and responsive layout
- `dist/assets/app.js` — Persian, English, Chinese and Arabic content
- `dist/assets/profile-000.jpg` — profile image supplied in the resume

## Deployment

The site is static and can be deployed directly to Cloudflare Pages. Set the build output directory to `dist`; no build command is required.

Production work is developed on `develop`. Merge into `main` only after final review.
